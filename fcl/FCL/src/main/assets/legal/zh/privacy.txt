FCLRust 隐私政策

版本：1
更新日期：2026 年 11 月 20 日

FCLRust（以下简称"本软件"）是一个安卓平台的 Minecraft Java 版启动器，基于 Fold Craft Launcher 开发，用 Starling 引擎替代 JVM 运行游戏。我们重视你的隐私。本政策说明本软件会处理哪些信息、为什么处理、这些信息会发送到哪里，以及你可以如何管理它们。请在使用前仔细阅读。

一、概述

1. 本软件没有自己的账号体系。开发者不会出售或出租你的个人信息。
2. 本软件没有集成任何统计分析、广告或推送类第三方 SDK。
3. 大部分数据只保存在你的设备上。只有在使用联网功能时，你的设备才会直接连接相应的服务，这些服务会收到你的 IP 地址等网络请求信息。
4. 在你同意本政策和《用户协议》之前，本软件不会申请权限，也不会联网。

二、保存在你设备上的信息

以下信息由本软件在你的设备上处理和保存，开发者无法获取：

1. 账户信息：离线账户的用户名和 UUID；微软账户和外置登录账户的用户名、UUID、皮肤信息以及登录凭据（如访问令牌和刷新令牌）。账户信息保存在应用私有目录中，只用于登录对应的服务和启动游戏。
2. 游戏数据：游戏版本、模组、整合包、资源包、光影包、存档、截图和控制布局等。这些文件保存在共享存储的游戏文件夹或应用专属目录中。共享存储中的文件可能被文件管理器或其他获得存储权限的应用访问。
3. 设置：启动器设置、游戏设置、收藏和下载记录等。
4. 日志和崩溃报告：启动器日志、游戏日志、联机日志和崩溃报告，可能包含设备品牌和型号、系统版本、处理器和显卡信息、内存信息、文件路径以及游戏内的玩家名。日志保存在共享存储的游戏文件夹中，除非你主动分享或上传，否则不会离开你的设备。

三、游戏资源的生成

1. 首次启动某个版本时，本软件会用 Starling 的资源准备程序，从你已有的游戏文件中生成运行所需的资源（纹理、模型、语言、音效等）。这一步完全在你的设备上完成，生成结果只保存在你的设备上，不会上传。
2. 这一步会在设备上启动一个随安装包提供的 Java 运行时来解析游戏文件。该运行时只用于生成资源，不用于运行游戏本身。
3. 生成过程会读取游戏目录中的版本文件、库文件和资源索引；如果这些文件缺失，启动器会按你选择的下载源获取，这一过程遵循本政策中关于联网的说明。
4. 本软件会在游戏目录中写入由引擎读取的配置文件，例如记录你选择的图形后端的 horizon-args.txt。这些文件同样只保存在你的设备上。

四、联网功能与第三方服务

使用以下功能时，你的设备会直接连接相应的服务。这些服务会收到你的 IP 地址和完成请求所需的内容（如请求的文件、搜索关键词），部分请求还会附带本软件的版本号。这些服务由第三方或其他开源项目运营，会按照各自的隐私政策处理信息，开发者无法控制。

1. 更新检查与公告：本软件会自动从 GitHub 获取版本信息和公告。
2. 游戏与加载器下载：下载游戏本体、资源文件、依赖库和加载器时，本软件会按你选择的下载源连接 Mojang 和微软的官方服务器、BMCLAPI 镜像，以及 Forge、NeoForge、Fabric、Quilt、LiteLoader、OptiFine、Cleanroom 等项目及其依赖仓库的服务器或镜像（包括 HMCL 提供的元数据服务）。
3. 游戏内容搜索与下载：搜索、浏览和下载模组、整合包、资源包、光影包和世界时，本软件会连接 CurseForge、Modrinth 或其镜像 MCIM，并加载内容的图标和截图。请求会包含你的搜索关键词和筛选条件。

五、权限

本软件申请的权限仅用于实现对应功能。你可以随时在系统设置中撤回已授予的权限，撤回后对应功能将无法使用。

六、信息的存储与安全

1. 本软件不会将你的个人信息上传到开发者自己的服务器（开发者没有这样的服务器）。
2. 账户凭据保存在应用私有目录中，其他应用无法直接读取。
3. 共享存储中的游戏文件、日志和截图可能被其他获得存储权限的应用访问，请自行评估风险。

七、你的权利

1. 你可以随时查看、修改或删除设备上的游戏文件、设置和日志。
2. 你也可以清除应用数据或卸载本软件，以删除应用私有目录中的全部信息。
3. 撤回存储或网络权限后，相关功能将无法使用。

八、未成年人

如果你是不满 14 周岁的未成年人，请在监护人的陪同下阅读本政策，并在取得监护人同意后使用本软件。

九、本政策的更新

本政策可能会根据法律法规或功能的变化更新。更新后，本软件会在启动时展示新版本，并再次征求你的同意。

十、联系我们
