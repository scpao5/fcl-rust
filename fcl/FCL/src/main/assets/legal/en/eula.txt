1) The Software neither ships nor distributes any Minecraft game files. The version files, libraries and assets the game needs are either downloaded through the launcher or come from a copy you already have.

4) The first time resources are prepared, the Software starts a Java runtime that ships with the package to read the game's files. It is used only for that preparation, never to run the game.
